# BMAD Agentic Product Framework

Eight specialist AI agents — business analyst, product manager, UX specialist, solution
architect, developer (spawnable in parallel), QA tester, documentation writer and marketing
specialist — that run the full product lifecycle from requirements to production go-live
inside Claude Code (CLI, desktop app, or the VS Code extension).

```
/bmad-init My Product — one-line idea
/bmad-help
```

Full guide: [bmad/GUIDE.md](bmad/GUIDE.md)

> When the documentation-writer agent later writes your product's own README, it replaces
> this file; the framework guide stays in `bmad/GUIDE.md`.
